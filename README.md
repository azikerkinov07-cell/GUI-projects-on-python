# Python GUI Projects

A collection of simple desktop applications built with Python.

## Projects

### Registration Form
A simple registration form with input validation.

### Calculator
A basic calculator that evaluates mathematical expressions.

### Currency Converter
A simple currency converter with predefined exchange rates.

### Password Generator
A random password generator using letters, numbers and symbols.

## Technologies

- Python
- Tkinter
- CustomTkinter
- random
- string

## Installation

```bash
pip install customtkinter
```
